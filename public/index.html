Мои проекты

Текст и настройки сохраняются в этом браузере. Аудио хранится на сервере.

От песни до караоке

  1. Найди текст. Введи название и исполнителя или вставь свой текст.
  2. Добавь музыку. Выбери запись из VK Музыки при подключённом аудио API или загрузи свой минус/оригинал. Приложению нужен отдельный доступ VK к аудиометодам; токен хранится в секретах сервера.
  3. Проверь тайминги. LRC содержит время каждой строки. Без него используется примерное распределение. Подсветка слов внутри строки тоже приблизительная.
  4. Выбери оформление. Проверь видео в плеере и нажми «Создать караоке».
  5. Скачай MP4. Сервер обработает весь трек в формате 1080×1920. Это может занять несколько минут.

Это локальная версия для одного пользователя. Для публичного сервиса понадобятся учётные записи, лимиты, лицензированные источники музыки и профессиональное разделение вокала.
